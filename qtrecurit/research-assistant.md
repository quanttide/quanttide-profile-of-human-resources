# 大连医科大学课题组科研助理招聘启事

一、课题组简介

课题组长期聚焦心血管疾病与代谢，神经免疫交互机制研究，综合运用免疫学、分子生物学、单细胞多组学、生物信息学等手段，围绕心肌纤维化、动脉粥样硬化、神经炎症等疾病中的免疫-间质/神经互作开展基础与转化研究。课题组依托大连医科大学附属第二医院，与海内外顶尖科研机构保持深度合作。现因科研工作需要，公开招聘科研助理2名。

二、招聘岗位

岗位一：实验方向科研助理（1名）

岗位职责：

1. 独立或协助开展分子生物学、细胞生物学及免疫学相关实验，包括但不限于细胞培养、免疫染色、蛋白印迹（Western Blot）、ELISA、流式细胞术、PCR及qPCR等；
2. 负责动物实验相关操作（如小鼠模型构建、组织取材、病理切片等）；
3. 参与实验室日常管理，包括仪器维护、试剂耗材采购与报销等；
4. 协助数据整理、分析及论文撰写。

应聘条件：

1. 具有免疫学、细胞生物学、分子生物学、心血管生物学、神经科学、基础医学等相关专业硕士学历（特别优秀者可放宽至本科）；
2. 熟练掌握免疫学及分子生物学基础实验技能；
3. 有动物实验经验，具备流式细胞术分析和分选经验者优先；
4. 工作积极主动，责任心强，具备良好的团队协作精神和沟通能力；

岗位二：生物信息学方向科研助理（1名）

岗位职责：

1. 负责高通量测序数据的分析与挖掘，包括单细胞转录组（scRNA-seq）、空间转录组、表观组等多组学数据的整合与可视化；
2. 开发或优化生信分析流程，搭建数据分析平台；
3. 协助团队成员设计生信分析方案，参与课题研究和论文撰写；
4. 跟踪生信与AI交叉领域的前沿技术，推动新方法在课题中的落地。

应聘条件：

1. 具有生物信息学、计算生物学、生物统计学、计算机科学或相关专业本科及以上学历；
2. 熟悉Linux系统及常用生信分析工具，熟练掌握R和Python等编程语言；
3. 熟悉高通量测序数据分析流程（如RNA-seq、单细胞测序等）；
4. 有单细胞多组学数据分析经验或公共数据库再分析经验者优先；
5. 具备良好的学习能力和科研热情，兼具生物医学背景者优先。

三、薪酬待遇

1. 提供具有竞争力的薪酬待遇（参考范围：4000-6000/月，具体面议），并视业绩给予额外奖励；
2. 表现优异者可获得深造推荐（攻读博士/博士后）或学术交流机会。

四、应聘方式

1. 应聘材料：个人简历（含基本信息、教育背景、科研/工作经历、发表论文等)。
2. 投递方式：请将材料电子版发送至邮箱：1073926653@qq.com，邮件主题注明“应聘岗位（实验/生信）-姓名-毕业学校”。
3. 招聘流程：初审通过者将通知面试。本招聘长期有效，至招到合适人选为止。
