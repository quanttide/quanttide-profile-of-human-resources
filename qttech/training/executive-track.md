# 高管培养路线

C-level 高职的培养路线已正式明确。职务设置参照腾讯已设立的高管职务及其分工，
**培养对象以画像定义，不对应具体人员**：

- **CIO 首席信息官**：侧重于维护现有大型系统。路径：CTO 助理 → 副秘书长 → 副总裁 → C level。
- **CXO 首席探索官**：侧重于发展新功能新方法。路径：CTO 助理 → 副秘书长 → 副总裁 → C level。
- **CPO 首席产品官**：侧重于产品体系和人类对接，包括产品策划、运营等产生商业价值。
  路径：CEO 助理 → 副秘书长 → 产品副总裁 → CPO。

CMO 等职务负责变现。
